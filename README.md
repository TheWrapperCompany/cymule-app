# Cymule for macOS

Release downloads for Cymule.app, the Cymule menu bar app for macOS.

This repository holds published, notarized app builds only. The source code is not published here.

- Product: https://cymule.com
- Publisher: The Wrapper Company — https://www.wrapper.company

Download the latest `Cymule-<version>.zip` from [Releases](https://github.com/TheWrapperCompany/cymule-app/releases), unzip it and move Cymule.app to Applications. Cymule requires macOS 26 or later.
